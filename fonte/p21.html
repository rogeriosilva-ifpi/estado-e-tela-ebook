20.4Listas de verificação

Antes de começar um projeto

  • Vite com proxy para a API; o código chama /api/..., nunca o endereço do servidor
  • AGENTS.md, INVARIANTES.md e docs/UI.md desde o primeiro commit
  • npm run gate com tipos, lint, fronteiras, testes e build

Ao revisar um componente

  • Key do domínio; nenhum componente definido dentro de outro
  • Nenhum estado que dê para calcular; nenhum dado do servidor em useState
  • Cada useEffect sincroniza com algo de fora e tem limpeza
  • Clicável é Botao ou link; foco visível; rótulo em todo campo

Ao integrar uma API

  • Contrato em docs/API.md, lido do código da API
  • fetch só em src/api/; erro vira ErroHttp com o status
  • Chaves em árvore; toda mutação diz o que invalida
  • Testes com o MSW na fronteira e uma jornada contra a API real

Autenticação e rotas

  • Quem entrou vem de /api/auth/me, no cache; nada no localStorage
  • Middleware antes dos loaders; 401 leva ao login e volta; 403 avisa no lugar
  • Botão por permissão; toda ação escondida tem 403 na API (porta-dos-fundos)
  • Loader não pede o que o papel não pode ler

20.5Glossário

Action. Função passada a <form action>; com useActionState, dá o estado do envio 6

Chave de consulta. Endereço de um dado no cache, em árvore: ["pacientes", id] 14

Context. Valor que chega a toda a subárvore sem passar por props 11

CSR, SSR, SSG. Onde e quando o HTML é montado: navegador, servidor a cada pedido, build 17

Efeito. Código que mantém algo fora do React em dia com o estado 7

Estado derivado. Valor calculável; não é estado 6

Hidratação. O React assume o HTML que veio do servidor e liga os eventos 17

Invalidação. Marcar dado do cache como velho, para buscar de novo 14

Key. Identidade de um item entre renders 3

Loader. Função da rota que carrega dados antes de a tela aparecer 13

Middleware. Função da rota que roda antes dos loaders 15

MSW. Responde pedidos HTTP nos testes, na fronteira da rede 16

Otimista. Mostrar o resultado antes da resposta e reverter se falhar 14

Permissão. O que o papel pode fazer em geral, vindo de /api/auth/me 15, 19

Props. Dados que o pai passa ao filho; o filho não altera 5

Reconciliação. Comparar a árvore nova com a anterior por tipo, posição e key 3

Reducer. Função pura (estado, ação) → próximo estado 12

Render. O React chama o componente para saber como a tela deve ficar 3

Server Component. Componente que roda só no servidor e não vai para o bundle 17

Sessão. Quem entrou, guardado no servidor e lembrado por cookie HttpOnly 15

StrictMode. Em desenvolvimento, monta duas vezes para expor efeito sem limpeza 2, 7

Token de design. Variável CSS com cor, espaço ou raio nomeados 9

401 · 403. Ninguém entrou · entrou, mas não pode 15
